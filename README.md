# 颜邦杰 · 亚马逊运营知识库

纯静态个人博客，无需安装依赖或构建，可部署到 Vercel 或 GitHub Pages。

## 内容

- 颜邦杰个人介绍、六个专业领域及运营决策速查。
- 三个明确标注的模拟项目：利润优化、新品增长、供应链协同。
- 六篇完整笔记：关键词投放、新品与排名、评论洞察、利润模型、FBA 补货、Listing 转化。
- 响应式布局、深浅色切换、手机导航、本地仓储配图和 favicon。

模拟项目、角色与业绩数字均为虚构演示，不能作为真实任职或业绩证明。发布真实案例前，应核实数字、时间范围和权限，并替换相应说明。

## 本地预览

直接在浏览器打开 `index.html`，文章、图片和脚本均使用相对路径。

## 配置

个人姓名、角色、邮箱、GitHub 地址在 `site-config.js` 中设置。邮箱未提供时不显示邮件按钮。首页静态标题、作者、介绍与文章署名应在更换作者时一并修改。

`domain` 预留给真实部署地址，目前为空。由于尚未确定部署域名，项目不发布含示例域名的 sitemap。正式部署后，创建包含首页及 `posts/` 下六篇文章绝对地址的 `sitemap.xml`，再在 `robots.txt` 添加它的完整 URL。

## 部署

Vercel 导入本仓库，Framework 选 Other，无需 Build Command。GitHub Pages 可从 `main` 的仓库根目录发布。文章均为独立 HTML，不依赖路由框架。

新增文章时，参考 `posts/keyword-value.html`，更新文章内容、标题和描述，然后在首页 `.blog-grid` 增加对应链接。
